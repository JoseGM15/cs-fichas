# CS Fichas - Repositorio de Contenidos

Sitio web moderno para compartir documentos, fotos y textos de forma pública.

## Características

✨ **Interfaz intuitiva** - Diseño limpio y moderno con colores azul oscuro y gris claro

📁 **Tres categorías** - Organiza tu contenido en Documentos, Fotos y Textos

📥 **Descarga fácil** - Los usuarios pueden descargar archivos con un clic

📋 **Copiar contenido** - Copia texto directamente al portapapeles

🔐 **Acceso restringido** - Solo quien conoce la contraseña puede subir contenido

💾 **Almacenamiento local** - Los datos se guardan automáticamente en el navegador

📱 **Responsivo** - Se adapta perfectamente a móviles, tablets y escritorio

## Instalación

```bash
# Clonar el repositorio
git clone https://github.com/JoseGM15/cs-fichas.git
cd cs-fichas

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev

# Compilar para producción
npm run build
```
